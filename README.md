# Нейросеть, распознающая цифры 28×28 — «как у 3Blue1Brown»

[![Открыть в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ewanpy00/Deeplearning_workshop/blob/main/workshop.ipynb)

Полносвязная сеть **784 → 16 → 16 → 10** с двумя скрытыми слоями, написанная с нуля
на numpy. Никаких PyTorch и TensorFlow: прямой ход, обратное распространение ошибки
и градиентный спуск реализованы руками, ровно по формулам из
[видео 3Blue1Brown](https://www.youtube.com/watch?v=aircAruvnKk).

Точность на тестовой выборке MNIST — **94.5%** (обучение занимает ~15 секунд).

## Математика, которая реально в коде

Прямой ход — каждый слой это одно матричное умножение ([network.py:53](network.py#L53)):

```
z^l = W^l · a^(l-1) + b^l          взвешенная сумма входов
a^l = σ(z^l)                       σ(x) = 1 / (1 + e^(-x))
```

Стоимость — квадратичная, как в видео: `C = ½ · Σ (a^L − y)²`.
Для картинки с цифрой 3 «правильный ответ» y — это столбец из нулей с единицей на позиции 3.

Обратное распространение ([network.py:76](network.py#L76)) — четыре формулы:

```
δ^L = (a^L − y) ⊙ σ'(z^L)              ошибка выходного слоя
δ^l = (W^(l+1))^T · δ^(l+1) ⊙ σ'(z^l)  ошибка, протолкнутая на слой назад
∂C/∂W^l = δ^l · (a^(l-1))^T
∂C/∂b^l = δ^l
```

Градиентный спуск ([network.py:107](network.py#L107)): перемешиваем выборку, режем на
мини-батчи по 10 картинок и на каждом делаем шаг `W ← W − η · ∂C/∂W`.

Правильность градиентов проверяется численно: если сдвинуть один вес на ±ε и посчитать
`(C(w+ε) − C(w−ε)) / 2ε`, получится то же число, что и из backprop
(совпадение до 10⁻⁸).

## Демонстрации для воркшопа

**1. Как «загораются» нейроны.** `python visualize.py --index 0` покажет картинку
ASCII-графикой и активации всех четырёх слоёв. `--count 5` — несколько случайных картинок.

**2. Где сеть ошибается.** `python visualize.py --errors --count 5` покажет только
неправильно распознанные цифры. Хорошо видно, что сеть ошибается там же, где засомневался
бы человек, и что выходные активации в этих случаях «размазаны» между двумя вариантами.

**3. Что выучил первый слой.** `python weights.py` рисует веса всех 16 нейронов первого
слоя как картинки 28×28. В видео это ключевой момент: мы ожидаем увидеть детекторы
палочек и петелек, а видим шумные пятна. Сеть решает задачу, но не тем способом,
который придумал бы человек.

**4. Почему предобработка важна.** `draw.py` перед подачей в сеть обрезает рисунок,
вписывает в квадрат 20×20 и центрирует по центру масс — именно так сделаны картинки
в MNIST. На искусственно сдвинутых и отмасштабированных цифрах:

| | точность |
|---|---|
| подать «как нарисовано» | 25.7% |
| после `to_mnist()` | 92.7% |

Отличный повод поговорить о том, что качество данных решает не меньше, чем архитектура.

## Что можно покрутить на воркшопе

```bash
python train.py --hidden 30 30           # больше нейронов в скрытых слоях
python train.py --hidden 16              # один скрытый слой вместо двух
python train.py --eta 0.01               # слишком маленький шаг — учится еле-еле
python train.py --eta 30                 # слишком большой — «перепрыгивает» минимум
python train.py --cost cross-entropy --eta 0.5
```

Про стоимость: квадратичная (`mse`, по умолчанию) даёт 94.5%, кросс-энтропия при
подобранном η — 94.2%, то есть на такой маленькой сети разницы почти нет. Зато на
кросс-энтропии наглядно видно, зачем её придумали: множитель σ'(z) в формуле ошибки
выходного слоя сокращается, и насыщенные нейроны перестают тормозить обучение.

## Что студент вписывает руками

Всего четыре вещи, и каждая — про понимание, а не про синтаксис:

1. **`sizes = [___, 16, 16, ___]`** — сколько чисел приходит на вход и сколько бывает ответов.
   Если ошибётся, проверка объяснит: 28 · 28 = 784 пикселя, 10 цифр от 0 до 9.
2. **Два вызова в цикле обучения** — `backprop` считает, куда двигать веса, `apply_gradients`
   двигает. Это и есть вся суть обучения, поэтому пропуски стоят именно здесь.

Незаполненный пропуск даёт понятное сообщение, а не питоновский трейсбек:
`В списке sizes остался пропуск ___ — впиши вместо него число`.

После каждого блока идёт `check(1)` / `check(2)` — короткая проверка с объяснением.
Вторая реально обучает пробную сеть на 6000 картинках и убеждается, что точность растёт.

## Подробная версия: восемь шагов

| Шаг | Функция | Что пишут | Минут |
|---|---|---|---|
| 1 | `sigmoid` | формула $\sigma(z) = 1/(1+e^{-z})$, одна строка | 3 |
| 2 | `sigmoid_prime` | $\sigma'(z) = \sigma(z)(1-\sigma(z))$ | 3 |
| 3 | `init_network` | формы матриц весов, деление на $\sqrt{n}$ | 6 |
| 4 | `forward` | $z = Wa + b$, $a = \sigma(z)$ по слоям | 8 |
| 5 | `predict`, `accuracy` | `argmax` и доля совпадений | 4 |
| 6 | `backprop` | четыре формулы обратного распространения | 15 |
| 7 | `apply_gradients` | шаг $W \leftarrow W - \eta\,\partial C/\partial W$ | 3 |
| 8 | `train` | цикл по эпохам и мини-батчам | 8 |

Руками пишется 32 строки, остальное — заготовленный каркас.

**В проверках нет эталонных реализаций** — подглядеть нечего: они прогоняют код участника
и смотрят, согласуется ли он сам с собой и с математикой.

- `sigmoid_prime` сверяется с численной производной *твоей же* `sigmoid`;
- `forward` проверяется послойно: правда ли `zs[l] == W @ activations[l] + b`;
- `backprop` — численным дифференцированием: каждый вес сдвигается на $\pm\varepsilon$,
  и изменение стоимости сравнивается с посчитанным градиентом;
- `train` проверяется поведением: за две эпохи точность обязана перевалить за 55%.

Сообщения подсказывают причину, а не просто «неверно». Проверено на типичных ошибках:

| Что сделал участник | Что скажет проверка |
|---|---|
| забыл поделить градиенты на `m` | «формулы верны, но каждый градиент ровно в 6 раз отличается от численного. Дело в делении на размер батча» |
| `delta.sum(axis=1)` без `keepdims` | «grad_b[0] должен совпадать по форме с biases[0] — не забудь keepdims=True» |
| `W += eta * grad` вместо `-=` | «шаг должен быть W = W − eta · grad (мы спускаемся, а не поднимаемся)» |
| веса без деления на $\sqrt{n}$ | «веса слишком большие (std=0.997) … иначе z улетят в насыщение сигмоиды» |
| `sigmoid` без `np.clip` | галочка + замечание про переполнение в `np.exp` |
